# Pourquoi le facteur empirique est plus performant

## Raisons
1. Il capture des effets combinés non modélisés explicitement
2. Les formulations physiques testées sont trop simplifiées
3. Les données manquent pour calibrer les mécanismes détaillés
4. Le facteur global a plus de liberté pour s'ajuster aux résidus observés

## Conclusion
Le facteur empirique est plus flexible. Une formulation physique complète nécessiterait plus de données et des mécanismes plus précis.
