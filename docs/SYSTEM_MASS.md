# Masse du système

## Idée
Prendre en compte la masse totale (baryonique + équivalente à l'énergie) dans l'évolution.

## Effet
La masse effective augmente avec l'accumulation d'énergie, ce qui peut modifier le potentiel et l'amplification.

## Limite
Risque de double comptage si mal appliqué.

## Conclusion
Piste à explorer avec prudence.
