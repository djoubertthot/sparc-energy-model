# Empirical Global Factor

The age + Rd global factor is retained as the best-performing option.

## Reasons
- Improves WRMS from 45.8 to 43.9 km/s
- Compensates for model limitations
- Physically motivated as a proxy (age for accumulation history, Rd for trapping)

## Limitations
- Empirical, not derived from first principles
- Other physical formulations did not improve RMS
