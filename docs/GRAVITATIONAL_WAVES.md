# Ondes gravitationnelles et énergie galactique

## Énergie des ondes gravitationnelles
Les ondes gravitationnelles transportent de l'énergie, mais leur densité d'énergie moyenne dans l'univers est extrêmement faible.

## Estimation
La densité d'énergie des ondes gravitationnelles cosmiques est de l'ordre de 10^{-15} à 10^{-20} fois celle du CMB.

## Conclusion
Les ondes gravitationnelles n'apportent pas une contribution significative à l'énergie disponible pour les galaxies dans le cadre du modèle.
