# Temperatures with Varying c

## Point
In standard cosmology the CMB temperature scales as T ∝ 1/a. In varying-c models the temperature history can be modified, but must still match the observed blackbody spectrum and the recombination physics.

## Constraint
Any successful model must reproduce the measured CMB temperature of 2.725 K today and the acoustic peak structure.

## Status
Noted. Not part of the current galactic model.
