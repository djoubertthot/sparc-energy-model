# Modifier les termes existants

## Idée
Au lieu d'ajouter un facteur externe, modifier la dépendance déjà présente dans a_bary ou dans l'amplification.

## Exemple
Rendre β dépendant du type ou du rayon de façon douce.

## Avantage
Évite le double comptage.

## Note
Nécessite des tests locaux pour évaluer le gain.
