# Residuals for Late-Type Galaxies

## Performance
Late-type galaxies (Sd, Sm, Irr) are well described by the age + Rd model.

## Typical Values
- Residual median: +2 to +15 km/s
- RMS median: 20–33 km/s

## Interpretation
The model captures the essential physics for gas-rich, late-type systems.
