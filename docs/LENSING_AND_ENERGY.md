# Lentilles et énergie

## Option A
E0 = 0 → pas de masse équivalente supplémentaire.

## Conséquence
Les lentilles gravitationnelles doivent être expliquées uniquement par les baryons (avec Y* = 1.0).

## Note
Si un petit terme E0 était réintroduit, il contribuerait à la masse effective et donc aux lentilles.

## Conclusion
Avec Option A, le modèle repose uniquement sur les baryons pour toutes les observables.
