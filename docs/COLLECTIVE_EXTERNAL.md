# Effet collectif sur les sources externes

## Question
L'effet collectif (réabsorption multiple) peut-il s'appliquer au CMB et aux neutrinos ?

## Réponse
- Pour le CMB : partiellement (absorption par la poussière).
- Pour les neutrinos : non (interaction trop faible).

## Impact
L'effet collectif est principalement efficace sur les émissions internes (étoiles).

## Conclusion
Appliquer le facteur collectif aux sources externes n'apporte qu'une amélioration limitée.
