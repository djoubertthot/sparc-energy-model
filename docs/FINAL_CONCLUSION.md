# Conclusion finale

## Résultat principal
Seul le facteur correctif global (Âge + Rd) améliore le RMS médian de façon significative.

| Approche | WRMS |
|----------|------|
| Base | 45.8 km/s |
| **Âge + Rd global** | **43.9 km/s** |
| Autres formulations | ≥ 44.6 km/s |

## Conclusion
Les approches plus physiques testées n'ont pas surpassé le facteur empirique global.
