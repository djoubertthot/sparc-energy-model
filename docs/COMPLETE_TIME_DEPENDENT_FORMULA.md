# Formule complète dépendante du temps

## Masse
\[
M(t) = M_\mathrm{final} \times f_\mathrm{retention}(t)
\]

## Accélération baryonique
\[
a_\mathrm{bary}(t) = \frac{G M(t)}{R^2}
\]

## Amplification
\[
\mathrm{ampl}(t) = \left( \frac{a_0}{a_\mathrm{bary}(t)} \right)^\beta
\]

## Énergie accumulée
\[
E(t) = E_0 \times \int_0^t \mathrm{ampl}(t') \times M(t') \, dt'
\]

## Vitesse
\[
V^2(r) = V_\mathrm{bary}^2(r) + \frac{G}{r} \int \frac{E(t)}{c^2} 4\pi r^2 dr
\]
