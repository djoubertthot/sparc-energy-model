# Trous noirs supermassifs

## Facteur γ
Le comportement est similaire aux trous noirs stellaires : γ devient grand seulement très près de l'horizon.

## Échelle
Pour un trou noir de 10^8 M☉, le rayon de Schwarzschild est ~1 UA. Les courbes de rotation galactiques sont mesurées à des échelles de kpc, où γ ≈ 1.

## Conclusion
Le facteur γ reste négligeable pour les courbes de rotation, même avec un trou noir supermassif central.
