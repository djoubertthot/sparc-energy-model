# Integral Formulation with Y* = 0.7

## Decision
Adopt Y*_SPS_eff = 0.7 (including average mass loss).

## Time Integration
Terms that accumulate over time become integrals:
\[
E_{\rm accum} = \int_0^{t} \Phi(t') \times \epsilon(M(t')) \, dt'
\]
