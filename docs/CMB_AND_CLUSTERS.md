# CMB et amas

## CMB
Le fond diffus cosmologique mesure Ω_m / Ω_b ≈ 6.
Même avec Y* = 1.0, le rapport baryonique reste insuffisant.

## Amas
Les amas de galaxies ont un rapport masse dynamique / baryons ≈ 5–6.
Y* = 1.0 réduit le problème mais ne l'élimine pas.

## Conclusion
Ces observables nécessitent encore un facteur supplémentaire au-delà des incertitudes baryoniques galactiques.
