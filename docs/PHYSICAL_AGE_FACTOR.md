# Facteur d'âge physique

## Bases physiques connues
- Âge de l'univers : ~13.8 Gyr
- Âge stellaire typique early-type : 10–12 Gyr
- Âge stellaire typique late-type : 5–8 Gyr
- Temps de production de poussière : quelques Gyr

## Formulation proposée

\[
f_\mathrm{âge} = \frac{t_\mathrm{stellaire}}{10\,\mathrm{Gyr}}
\]

## Avantage
Ancré dans des quantités observables ( âges stellaires).

## Prochaine étape
Utiliser des âges réels quand disponibles, sinon le proxy morphologique.
