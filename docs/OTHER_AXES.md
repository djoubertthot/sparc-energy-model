# Other Axes of Improvement

## Possible Directions
1. **Better observational data** : real stellar ages, complete dust masses, environment metrics
2. **Quality cuts** : restrict to high-quality rotation curves (Q=1)
3. **Non-circular motions** : model bars, warps, and other kinematic disturbances
4. **Environment** : group vs field galaxies
5. **Stellar M/L variations** : more sophisticated mass-to-light ratios
6. **Machine-learning discovery** : flexible models to suggest new functional forms

## Recommendation
The highest-leverage next step is better ancillary data (ages, dust) on the SPARC sample.
