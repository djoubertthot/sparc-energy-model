# Comparaison interne vs externe

## Approche
Appliquer les mêmes connaissances physiques (effet collectif, piégeage, accumulation temporelle) séparément aux sources internes et externes.

## Sources internes
- Énergie stellaire
- Effet collectif fort (UV/optique)
- Piégeage modéré
- Accumulation sur l'âge

## Sources externes
- CMB + neutrinos + CIB
- Effet collectif faible
- Piégeage faible
- Accumulation sur l'âge

## Test
Comparer laquelle des deux sources, une fois correctement modélisée, réduit le mieux le facteur manquant et le RMS.

## Conclusion
Cette approche est plus physique que des dépendances ad hoc.
