# Perte de masse cumulative sur la vie des étoiles

## Calcul
La perte de masse par rayonnement est déjà intégrée sur 10 Gyr dans les estimations précédentes (~0.07 % pour une étoile de type solaire).

## Effet sur la vitesse
Même intégrée sur toute la vie de l'étoile, l'augmentation de vitesse orbitale reste de l'ordre de 0.03–0.07 %.

## Conclusion
L'effet cumulatif est toujours négligeable par rapport aux résidus observés (~30–50 %).
