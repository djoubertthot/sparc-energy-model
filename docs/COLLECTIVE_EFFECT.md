# Effet collectif

## Idée
Les photons émis par les étoiles sont réabsorbés et réémis plusieurs fois dans la galaxie, multipliant l'énergie effective.

## Limites
- Le temps de traversée d'une galaxie est court (~10^5 ans).
- La poussière réémet principalement en infrarouge.
- Le facteur de multiplication réaliste est limité (quelques unités à quelques dizaines).

## Conclusion
Un effet collectif existe, mais il est peu probable qu'il atteigne un facteur 550 sans mécanisme supplémentaire.
