# Y* variable

## Possibilité
Oui, Y* peut être variable d'une galaxie à l'autre en fonction de l'histoire de formation stellaire, de l'IMF, et de la présence de bulbes.

## Implémentation
- Y* = f(type, couleur, âge proxy)
- Ou optimisation par galaxie avec régularisation

## Avantage
Peut réduire le biais sur les early-types sans facteur empirique global.

## Limite
Risque de sur-ajustement si trop libre.
