# Facteur de Lorentz γ

## Définition
\[
\gamma = \frac{1}{\sqrt{1 - v^2/c^2}}
\]

## Dans le modèle
Pour les vitesses galactiques (v ~ 100–300 km/s), v/c ~ 10^{-3}, donc γ ≈ 1.0000005.

## Conséquence
Le facteur γ est négligeable et peut être pris égal à 1 sans perte de précision pour les courbes de rotation.

## Conclusion
Il n'apporte pas d'effet significatif dans le contexte galactique.
