# Sources de données supplémentaires

## Âges stellaires
- Études SED (Marasco et al. 2025, et autres)
- Catalogues de populations stellaires

## Masse de poussière
- Herschel (catalogues de galaxies locales)
- IRAS

## Métallicité
- Études individuelles
- Catalogues de gradients de métallicité

## Faisabilité
Possible pour un sous-échantillon de SPARC. Nécessite un croisement manuel ou semi-automatique.

## Prochaine étape
Identifier les galaxies SPARC présentes dans ces catalogues.
