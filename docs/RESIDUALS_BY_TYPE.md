# Résidus par type morphologique

## Modèle Âge + Rd

| Type | Résidu médian | RMS médian |
|------|-----------------|-------------|
| Early | +80 km/s | 91 km/s |
| Inter | +35 km/s | 44 km/s |
| Late | +3 km/s | 20 km/s |

## Conclusion
Le modèle est bien adapté aux late-types, mais sous-estime fortement les early-types.
