# Résultats sur les amas

## Observations
- Amas massifs : fraction baryonique ~15 %
- Groupes : déplétés (~3 %)
- 70 % des baryons dans l'IGM

## Implication
La tension est moindre pour les amas massifs. Les baryons sont redistribués à grande échelle.

## Conclusion
Compatible avec un modèle baryonique étendu.
