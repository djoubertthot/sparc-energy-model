# Données Gaia

## Utilité
Gaia fournit des vitesses et distances précises pour les étoiles de la Voie Lactée.

## Application
- Contraindre la courbe de rotation locale
- Tester Y* sur la Voie Lactée
- Vérifier la cohérence du modèle à petite échelle

## Conclusion
Gaia est une ressource importante pour valider le modèle sur notre galaxie.
