# Adoption of Y* = 1.0

## Decision
The model now uses Y* = 1.0 as the reference stellar mass-to-light ratio.

## Justification
- Compatible with the upper end of IMF/SPS uncertainties
- Significantly improves the RMS (from 45.8 to 27.8 km/s in pure baryonic tests)

## Status
Updated as the current reference value.
