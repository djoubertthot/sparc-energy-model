# Résolutions de la tension SPS

## 1. IMF variable
- Plus d'étoiles de faible masse dans les galaxies massives
- Y* plus élevé pour les early-types

## 2. Masse baryonique cachée
- Gaz moléculaire froid
- Naines brunes
- Objets compactes non lumineux

## 3. Combinaison
- IMF légèrement plus lourde + une partie de masse cachée

## Conclusion
Les trois pistes sont à explorer avec des données supplémentaires.
