# Implications cosmologiques

## Modèle
Y* = 1.0, Gaz ×2, CGM ×3.5

## Implications
- Tension CMB fortement réduite
- Amas dans les incertitudes

Le modèle est compatible avec la cosmologie dans la limite des incertitudes baryoniques.
