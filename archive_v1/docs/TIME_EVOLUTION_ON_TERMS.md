# Application de l'évolution temporelle

## Termes potentiellement affectés
1. E0 (accumulation)
2. a_bary via Y*(t)
3. Amplification via a_bary(t)
4. Facteurs de piégeage si dépendants de la densité historique

## Limite
Tous les termes ne doivent pas être intégrés ; seulement ceux qui ont un sens physique cumulatif.

## Conclusion
L'intégrale s'applique principalement aux termes d'accumulation d'énergie.
