# Trous noirs et le modèle

## Facteur γ
Près de l'horizon, les vitesses sont relativistes et γ devient grand.

## Applicabilité
Le modèle actuel est conçu pour les courbes de rotation galactiques, pas pour les régimes proches des trous noirs.

## Conclusion
Le facteur γ est négligeable pour les galaxies, mais important près des trous noirs. Le modèle n'est pas destiné à décrire ces régions.
