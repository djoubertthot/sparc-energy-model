# Rôle de Y* dans le modèle

## Avec Y* = 1.0
Y* reste nécessaire pour convertir la luminosité en masse stellaire, mais sa valeur est maintenant fixée à 1.0.

## Formule
M_stellaire = 1.0 × L_3.6

## Conclusion
Le rapport n'est plus un paramètre libre, mais il reste présent dans la conversion masse/luminosité.
