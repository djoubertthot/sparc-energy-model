# Résidus radiaux

## Observation
Les résidus augmentent avec le rayon (sous-estimation en périphérie).

## Interprétation
Le modèle baryonique pur (Y*=1.0) capture bien le centre mais sous-estime les parties externes.

## Prochaine étape
Explorer une dépendance radiale légère ou une masse étendue.
