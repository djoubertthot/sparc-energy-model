# Effet collectif — Évaluation raffinée

## Réalisme
Un facteur de multiplication de ×2 à ×10 est **réaliste** dans les galaxies, en particulier dans les régions poussiéreuses.

## Impact
- Facteur manquant réduit de ~550 à ~50–275.
- Améliore le bilan, mais ne comble pas l'écart.

## Conclusion
L'effet collectif peut être inclus comme un facteur d'efficacité raisonnable, mais un mécanisme supplémentaire reste nécessaire pour atteindre le facteur total.
